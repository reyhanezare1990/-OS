
### شرح تمرین
با استفاده از دستور `man ls` سوئیچی را پیدا کنید که فایل‌ها را بر اساس حجم مرتب می‌کند.

### پاسخ تمرین

echo "Hi" > file1.txt
echo "Hello World" > file2.txt
echo "This is a medium text file" > file3.txt
echo "This is a much longer text file for testing file size sorting" > file4.txt
```

دستور در ترمینال
ls -S
